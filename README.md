# :rocket:**Tên dự án:** SmartCampus

Ứng dụng di động giúp sinh viên PTIT ***tra cứu lịch học, phòng trống và nhận thông báo mới nhất từ nhà trường***

## :rocket:Tính năng chính đã hoàn thành

* Tra cứu lịch học theo mã sinh viên
* Xem danh sách phòng trống theo tòa nhà

  * trong phần map trường sẽ hiện cho mọi người biết phòng nào đang trống theo từng toà khác nhau

## :rocket:**Tính năng đang phát triển**

* Thông báo đẩy (push notification)
* Đăng nhập bằng tài khoản trường

Đôi nét về CLB của trường PTIT ví dụ như clb lập trình [CLB lập trình](https://proptit.com/) và kèm theo đó là logo cho dự án này !\[logo](https://vstatic.vietnam.vn/vietnam/resource/IMAGE/2025/11/07/1762482341955\_faker.jpeg)

>\\\*\\\*\\\*cảnh báo: dự án đang trong giai đoạn phát triển, chưa dùng cho mục đích chính thức\\\*\\\*\\\*

\---

``` bash

git clone https://github.com/clb-lap-trinh/smartcampus.git
npm install
npm start
```

* \[x] tra cứu lịch học theo mã sinh viên
* \[x] Xem danh sách phòng trống theo tòa nhà
* \[ ] Thông báo đẩy (push notification)
* \[ ] Đăng nhập bằng tài khoản trường

|Thư viện|Phiên bản|Mục đích|
|:-:|-:|-|
|React Native|0.74|Xây giao diện đa nền tảng iOS/Android|
|Axios|1.6|Gọi API lấy dữ liệu lịch học|

Trong phần giao diện web này còn có một tính năng rất hay khi nhấn vào \\# sẽ có thêm phần ẩn
